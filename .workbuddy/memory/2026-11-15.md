# 2026-11-15

## easyfk-generator：补齐 Gradle Kotlin DSL（build.gradle.kts）项目生成

- 背景：`GradleType` 枚举早有 `KOTLIN`，CLI 也支持 `gradle-type`，但 `templates/project/gradle/kotlin/` 目录不存在，且 `ProjectGenerator` 的 single / micro_prd / master 根脚本分支只处理 GROOVY，选 kotlin 会拿到 null 模板直接抛异常；另有两处模板名写错（`springcloud_api_build` / `sc_client_build`）。
- 方案：新增 22 个 `gradle/kotlin/*.gradle.kts.ftl`，与 groovy 模板一一对应（同名同逻辑，只换 DSL）；`ProjectGenerator` 抽出 `createRootGradleConfigFile(rootConfigFile, prefix)` 统一 master/single/micro_prd 的 build+settings 模板选择，并修正两处 kotlin 模板名。
- Kotlin DSL 与 Groovy 的几个坑（已实测验证）：
  - `versionCatalogs { libs { library(...) } }` 在 kts 中必须写 `versionCatalogs { create("libs") { library(...) } }`。
  - root 脚本的 `subprojects {}` 块里不能用 `libs.xxx` 访问器（报 "Extension with name 'libs' does not exist"），要用 `extensions.getByType<VersionCatalogsExtension>().named("libs").findLibrary("x").get()`。
  - `annotationProcessor(libs.a, libs.b)` 多参会被解析成 `String?` 重载而编译失败，必须逐个传 `.get()`。
  - 子模块脚本要拿到 `api/implementation` 等访问器，需自带 `plugins { \`java-library\` }`（root 里 `apply(plugin=...)` 不生成访问器）。
  - groovy 的 `[compileJava, compileTestJava]*.options*.encoding` → `tasks.withType<JavaCompile>().configureEach { options.encoding = "UTF-8" }`。
  - `copyJar` 的「delete + Copy」改为 `tasks.register<Sync>`（自动清理目标目录，产物一致且配置缓存友好）。
  - kts 里不要写 `${...}` 字符串模板（会和 Freemarker 冲突），用 `"lib/" + it.name` 拼接。
- 验证方式：本机 `gradle`（9.6.1，`D:/maven_repository/gradle` 有缓存，需 `--offline`）分别生成 smart_orm / microservice / single / micro_prd 的 groovy 与 kotlin 工程：
  - `gradle projects` 全部脚本编译 + 工程树解析通过；
  - 逐模块 dep 坐标 diff 无差异；jar 的 `MANIFEST.MF` 与 `build/libs/lib`（141/117 个 jar）与 groovy 完全一致；
  - 本地仓库注入 `maven { url = uri("file:///D:/maven_repository/repository") }` 可实际构建 jar（auth-* 3.5.16 本地缺失，验证时用 include-auth=false）。
- 测试：`GeneratorSmokeTest` 新增 `generatesGradleKotlinDslAtFrameworkVersion`。项目 `build.gradle` 里 `test { enabled = false }`，跑测试需临时用 init script `afterEvaluate { tasks.withType(Test) { enabled = true } }` 绕过。
- 顺带：`generator-template.yml` 补 `gradle-type` 说明，使用手册构建文件表格补 kotlin 一行。
