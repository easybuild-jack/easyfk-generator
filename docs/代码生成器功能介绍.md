# EasyFK Generator — 企业级全栈代码生成器

> **一次配置，全栈生成。** 从项目骨架到完整业务代码，分钟级交付生产就绪的 Java 工程。

---

## 产品定位

EasyFK Generator 是 **易架构（EasyFK）** 框架体系的核心基础设施，面向 Java / Spring Boot 技术栈的企业开发团队，提供 **配置驱动、数据库感知、全层覆盖** 的一站式代码生成能力。

无论是从零搭建新项目，还是在已有项目中快速扩展业务模块，EasyFK Generator 都能在分钟内产出规范、一致、可立即运行的工程代码，彻底消除重复性编码工作。

---

## 核心特性

### 1. 三种架构形态，一键切换

通过一个配置项即可切换项目架构类型，无需手动调整项目结构：

| 架构类型 | 适用场景 | 生成产物 |
|----------|----------|----------|
| **SINGLE（单体）** | 中小型项目、快速原型 | 单一工程，所有分层代码集中在一个项目中 |
| **MICROSERVICE（微服务）** | 标准微服务拆分 | API 模块 + Server 模块 + PRD 模块，支持 Spring Cloud 或 Dubbo |
| **SMART（多栈微服务）** | 大型平台、多协议互通 | 同时生成 Spring Cloud 和 Dubbo 两套 RPC 通道，自由切换调用方式 |
| **SMART_ORM（多栈微服务 + ORM 抽离）** | 多 ORM 并存、按需选型 | 在 SMART 基础上将 ORM 层抽离为 `-orm-api`（契约）+ `-orm-plus/-orm-flex/-orm-hibernate`（实现）独立模块，server 编译期不绑定具体 ORM，运行时按依赖自动装配 |

```yaml
easyfk.config.generator.project:
  project-type: smart  # 只需修改这一行
```

### 2. 完整分层代码，全栈覆盖

每张数据库表自动生成 **8 ~ 15 个 Java 类**，覆盖标准分层架构的每一层：

```
数据库表
  ├── Entity（实体类，含字段映射与注解）
  ├── Mapper（MyBatis / MyBatis-Flex 接口 + XML）
  ├── Repository + RepositoryImpl（数据仓储层）
  ├── Service + ServiceImpl（业务逻辑层）
  ├── API 接口（适用于 SMART 架构）
  ├── DTO / Param / Req / Resp / EditReq（数据传输对象）
  ├── SpringCloud Remote + RemoteImpl（远程调用客户端）
  ├── Dubbo Remote + RemoteImpl（Dubbo 远程调用）
  └── Controller（RESTful 接口层）
```

生成的代码遵循统一的编码规范与最佳实践，开箱即用。

### 3. 数据库元数据驱动

直连数据库，自动完成 **表结构 → Java 代码** 的完整映射：

- **自动读取表结构**：通过 JDBC DatabaseMetaData 解析字段名、类型、注释、主键等信息
- **智能类型映射**：`DATETIME` → `LocalDateTime`，`DECIMAL` → `BigDecimal`，`BIGINT` → `Long` 等
- **注解感知**：识别 Entity 中的 `@SingleUniqueField`、`@CombUniqueField`、`@BetweenConditionField`、`@ForbiddenField` 等自定义注解，自动在 Repository / Service / Controller 层生成对应的唯一性校验、区间查询、启用/禁用等业务逻辑
- **表前缀处理**：自动剥离表名前缀，生成干净的类名

### 4. 广泛的数据库支持

内置 **22 种数据库** 适配，覆盖主流商业数据库与国产信创数据库：

| 类别 | 数据库 |
|------|--------|
| 主流关系型 | MySQL、MariaDB、PostgreSQL、Oracle（11g / 12c+）、SQL Server |
| 国产信创 | 达梦（DM）、人大金仓（KingbaseES）、南大通用（GBase）、神通（Oscar）、虚谷（XuGu） |
| 分布式/云原生 | OceanBase、ClickHouse、GaussDB |
| 嵌入式/其他 | H2、HSQL、SQLite、DB2、Firebird、Sybase ASE |

### 5. 双构建体系支持

同一项目可选择不同的构建工具，模板自动适配：

| 构建工具 | 支持类型 |
|----------|----------|
| **Maven** | 标准 pom.xml，适合传统团队和 CI 环境 |
| **Gradle Groovy DSL** | build.gradle + settings.gradle |
| **Gradle Kotlin DSL** | build.gradle.kts + settings.gradle.kts |

三种构建方式均覆盖全部项目类型（SINGLE / MICROSERVICE / SMART），切换只需修改一行配置。

### 6. 灵活的 PRD 层策略

前端对接层（PRD / Controller）支持三种部署策略，适配不同的前后端协作模式：

| PRD 类型 | 说明 |
|----------|------|
| **NONE** | 不生成 Controller 层，纯服务端项目 |
| **SINGLE** | 单一 PRD 项目，所有 Controller 集中部署 |
| **SEPARATION** | 分离式：`prd-client`（C 端 / 用户端）+ `prd-bms`（B 端 / 管理后台），各自独立部署 |

### 7. 增量生成，安全无忧

- **已有文件不覆盖**：使用 `createOnNotExistFile` 策略，生成器不会覆盖你已手动修改的代码
- **可选强制刷新**：DTO 和 Param 等随表结构变化的类使用 `delAndCreateFile` 策略，确保与数据库保持同步
- **单独更新 DTO/Param**：`updateDtoAndParam()` 支持仅刷新数据传输对象，不影响其他代码层

### 8. Spring Boot Starter 集成

以标准 Spring Boot Starter 方式提供，**零侵入** 接入已有项目：

- 引入依赖即自动装配，无需手动注册 Bean
- 所有配置通过 `application.yml` 集中管理
- 生成器本身也会为生成的项目生成 `AutoConfiguration` 配置，确保模块化的自动装配

### 9. 资源权限注解生成

内置资源权限体系支持，可为每个 Controller 接口自动生成资源权限注解：

- 资源分组、资源名称、资源 ID、前端路由路径
- 自动排序编号，支持增量起始值配置
- 与 EasyFK 框架的权限管理体系无缝对接

## 快速上手

### 第一步：添加依赖

**Gradle:**

```groovy
implementation 'com.mcst:easyfk-generator:3.5.16'
```

**Maven:**

```xml
<dependency>
    <groupId>com.mcst</groupId>
    <artifactId>easyfk-generator</artifactId>
    <version>3.5.16</version>
</dependency>
```

### 第二步：编写配置

```yaml
easyfk:
  config:
    generator:
      project:
        project-dir: D:\workspace\projects
        group-id: com.example
        project-name: my-app
        project-type: smart           # single / microservice / smart
        prd-type: separation          # none / single / separation
        build-type: gradle            # maven / gradle
        orm-type: MYBATIS             # MYBATIS / MYBATIS_FLEX
        base-package: com.example.myapp
        framework-version: 3.5.16

      code:
        module-name: myapp
        db-short-url: localhost:3306/my_database
        db-user: root
        db-pwd: your_password
        model-list:
          - model-name: Product
            model-desc: 商品信息
          - model-name: Order
            model-desc: 订单信息
```

### 第三步：一键生成

```java
@Resource
private EasyfkGenerator easyfkGenerator;

// 全量生成：项目骨架 + Entity + 业务代码 + 自动装配
easyfkGenerator.generateAll();

// 或按需分步生成
easyfkGenerator.generateProject();       // 仅项目骨架
easyfkGenerator.generateModel();         // 仅 Entity + Mapper
easyfkGenerator.generateCode();          // 仅业务代码
easyfkGenerator.generateConfig();        // 仅自动装配配置
easyfkGenerator.updateDtoAndParam();     // 仅刷新 DTO/Param
```
